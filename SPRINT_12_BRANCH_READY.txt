================================================================================
                        R23 WORKFLOW SUMMARY
================================================================================

The 4-Step Cycle (Per Feature):

  STEP 1: DEVELOP LOCALLY
    1. Edit code
    2. pytest (until ✅ green)
    3. mypy (until ✅ clean)
    4. git commit (pre-commit hooks run)
    5. Repeat until feature complete

  STEP 2: PUSH TO FEATURE BRANCH
    1. git push origin feature/sprint12-monte-carlo
    2. Terminal shows: "Create a pull request" link

  STEP 3: WAIT FOR CI
    1. GitHub Actions triggers automatically
    2. pytest runs: ✅ PASS or ❌ FAIL
    3. mypy runs: ✅ PASS or ❌ FAIL
    4. linting runs: ✅ PASS or ❌ FAIL
    5. If all pass: Merge button appears in PR
    6. If any fail: Fix code, commit, push, re-run

  STEP 4: MERGE & CLEANUP
    1. Click "Merge pull request" on GitHub
    2. Choose "Squash and merge"
    3. Delete branch locally: git branch -d feature/sprint12-monte-carlo
    4. Delete branch remotely: git push origin --delete feature/sprint12-monte-carlo
    5. Sync main: git pull origin main
    6. Sanity check: pytest tests/api/ --no-cov -q

Time per feature: ~20-30 minutes (including CI wait)
