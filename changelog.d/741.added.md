Infeasibility diagnostics + optimization audit log (#741): when a
capital-structure / single-parameter optimizer search finds no feasible
candidate, the result now carries a structured `InfeasibilityDiagnostics`
(per-covenant which bound was violated, the required vs the closest achieved
value, the signed shortfall, and how many candidates it bound) plus a
lightweight `OptimizationAuditLog` (method, evaluations, iterations, final
status, binding constraints) via new `analytics.infeasibility_diagnostics`.
Populated ONLY on the infeasible path — a feasible solve leaves `diagnostics`
and `audit_log` at `None` and is byte-identical to before (opt-in analysis
optimizers only; never read by `run_v14_pipeline`).
