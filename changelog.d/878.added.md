- **BESS grid-capability plug-in (SoH-degraded reactive + manual PCS short-circuit contribution)** (`analytics/grid/capabilities/bess.py`, `analytics/grid/capabilities/__init__.py`, `analytics/grid/__init__.py`, #878 D4d) — first per-technology grid-capability plug-in in the new `analytics/grid/capabilities/` package, keyed on the `finance.tech_types` storage classification (`is_storage_type` → `bess`). For one BESS site it answers the two design-stage grid questions a storage converter frames differently from a generation resource: (1) the **PCS short-circuit contribution is a MANUAL config input** (`grid.sc_contribution_pu`, pu on the rated-MVA base) with NO silent default (CESSPIT) — the current-limited PCS fault current is NOT carried in the OEM `.dyr` per the DIgSILENT manual, so an absent/negative/non-numeric value is REJECTED rather than assumed; it is folded into the D1 SCR screen (`analytics.grid.short_circuit.screen_grid_strength`) as an addition to the POC fault level (a BESS PCS stiffens the grid → raises the SCR); and (2) the **reactive / apparent-power capability DEGRADES with state-of-health** — a `grid.soh_curve` (year → SoH fraction) scales both the converter MVA rating and the ± Mvar reactive headroom, so the year-15 reactive headroom shrinks as the battery ages (the binding end-of-life PQ-box case). The SoH-degraded reactive verdict reuses the D3 `analytics.contracts_v14.ReactiveCapabilityResult` (CCCDIR — no new result type invented) and the SCR band reuses `GridStrengthResult`. STANDALONE module with pure entry points (`bess_sc_contribution_pu`, `degrade_bess_rating`, `screen_bess_capability`, `BessDegradedRating`) — a later dolphin wires the per-tech dispatch into the `evaluate_grid` gateway. CASPER: no grid library is imported at module scope; the reused SCR screen guards `pandapower` at call-time and transparently uses its closed-form Thevenin fallback when the `[grid]` extra is absent, so the default (grid-free) install imports and runs the plug-in cleanly. Default-off / additive: nothing here feeds the finance engine, so committed-scenario KPIs are byte-identical (project/equity IRR, NPV, min DSCR unchanged). Grid-free tests carry 100% coverage of the new module (the strict `sc_contribution_pu` parser, the `soh_curve` resolver, the reactive-rating derivation, `degrade_bess_rating`, and the end-to-end closed-form screen incl. the storage-type gate); the pandapower IEC 60909 SCR path runs in the opt-in `-m grid` lane with the `[grid]` extra installed.
