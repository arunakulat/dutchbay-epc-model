- Correct normalize_kpi_dict's docstring, which claimed it "logs warnings for skipped entries" while the code emitted logger.debug, and pin the corrected behaviour with controls. Raising the log level was rejected on evidence rather than preference: the function sits on the return_full_result=False default path of the sole evaluation gateway, which the Monte Carlo engine, five sensitivity modules, the tornado builder, the parameter solvers and two optimizers all call per iteration, so a warning per dropped entry would flood those runs. The docstring now states that the drop is DEBUG-only and therefore silent in ordinary operation, that a dropped entry is absent rather than defaulted or zero-filled, and that a caller which must not lose entries passes return_full_result=True and bypasses the function entirely, which is what Dolphin 3C requires of any contract-facing capture. Three controls pin it, including a negative control observed to fire when the debug call is patched to warning. Closes D3C-ASR-02 from the Dolphin 3C contracts disposition.
