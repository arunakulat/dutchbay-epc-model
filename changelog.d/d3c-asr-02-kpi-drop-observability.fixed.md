- Correct normalize_kpi_dict's docstring, which claimed it "logs warnings for skipped entries" while the code emitted logger.debug, and pin the corrected behaviour with controls that were each observed to fail. Raising the log level was rejected on evidence rather than preference: the function sits on the return_full_result=False default path of the sole evaluation gateway, which the Monte Carlo engine, five sensitivity modules, the tornado builder, the parameter solvers and two optimizers all call per iteration, and the drop set is type-structural and data-invariant, so a warning per dropped entry would emit the same constants thousands of times per run. The docstring now states the actual drop predicate (float() raising TypeError or ValueError, with other exception classes propagating), that the drop is DEBUG-only and therefore silent in ordinary operation, that a dropped entry is absent rather than defaulted or zero-filled, that a bool is coerced rather than dropped so a boolean KPI such as wacc_is_real arrives downstream as a finite 0.0, and that return_full_result=True is a remedy on evaluate_with_overrides only, since evaluate_scenario_from_dict and evaluate_with_casper_tail_risk have no such parameter. The divergence from analytics.casper.casper_payload is stated as what it is rather than as bool-only: that normalizer admits a key only when isinstance(v, (int, float)) and not isinstance(v, bool), so the two also disagree on every value float() accepts that is neither int nor float -- numeric strings, Decimal, Fraction, and any object defining __float__. A scenario named "2030" is the live case, arriving here as the phantom KPI scenario_name=2030.0 and absent from the CASPER payload; the disagreement runs one way only, so the risk is a phantom KPI rather than a lost one. The emitted level, the caller boundary and CASPER's admission rule are all derived from source by AST rather than restated as prose, and every sentence mentioning a warning must both carry a counterfactual marker and make no present-tense emission claim. That is a gate over what the docstring may assert, not a proof that prose and code agree: twelve mutants drawn from two rounds of independent review are killed by it, including the three that survived the previous controls, but a sufficiently inventive wording could still pass.
