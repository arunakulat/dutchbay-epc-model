The INTAKE-01 check (`scripts/ci/check_pr_intake.py`, job "Verification intake" in the
PR Receipts workflow) now requires a PR's open-PR sweep to name only the PRs that were open
when that PR was opened, as INTAKE-01 states ("before opening a PR"). A PR opened later no
longer fails every older PR's intake; its own sweep names the older one. A missing or
unreadable creation time still requires the PR (fail closed) (#1875).
