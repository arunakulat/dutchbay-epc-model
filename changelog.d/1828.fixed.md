- The DFI workbook foundation (`analytics/dfi_workbook/foundation.py`) now refuses display
  formats that would show a reader something other than the stored value (#1828). Text and
  boolean inputs accept only `General` or `@`, so a format such as `;;;` can no longer blank a
  text cell and `;;;"X"` can no longer show a different word. An explicit negative section must
  print the sign as `-` or parentheses, so `0.0;0.0` can no longer show `-1234.5` as `1234.5`,
  and the positive and zero sections may print neither. Conditional sections such as
  `[>=1]0.00;0.0%` are refused, because LibreOffice drops the sign in them. Quoted literals
  may hold only a unit token (`%`, `x`, `MW`, `MWh`, `kWh`, `GWh`, `USD`, `LKR`, `days`,
  `years`, `yrs`) or one punctuation character, so free wording such as `" (lender case)"`
  can no longer sit beside a value. The package is reached from no pipeline root, so no
  shipped output or KPI changes.
