- **RIX / ΔRIX terrain-ruggedness envelope diagnostic** (`analytics.gis.rix`, #831) — compute the Ruggedness Index (RIX = fraction of terrain within a radius steeper than a critical slope, config default 0.3 ≈ 16.7°) from the DEM slope raster (#829), report ΔRIX = RIX(turbine) − RIX(reference/mast), and DISCLOSE when |ΔRIX| exceeds a config threshold (default 5%) — the point above which linear-flow / reanalysis (WAsP / ERA5) assumptions need a terrain correction (Mortensen, Bowen & Antoniou 2006). Config-first (critical slope, radius, threshold); NaN nodata excluded from the steep-fraction; optional provenance-stamped RIX GeoTIFF export via the #20 helpers (CASPER-guarded). KPI-neutral read-only diagnostic — not wired into any AEP/energy/finance calc.
