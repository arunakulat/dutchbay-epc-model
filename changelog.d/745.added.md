Cross-technology headline-KPI comparison section in the lender report + CLI (#745 slice-1). A
side-by-side table compares the headline KPIs (project IRR, equity IRR, minimum DSCR, project NPV,
total CFADS, gearing) of multiple scenario configs. This slice is the 2-way comparison of the wind
lender case and the hybrid case that exist. Each compared config is run through the CANONICAL v14
pipeline (strict validation), so every column reconciles exactly to that config's own committed
headline KPIs (the lender-integrity basis) rather than a non-canonical snapshot. Opt-in and
latency-gated: the multiple full-pipeline runs are heavy, so the block is built out-of-band via the
new `app.reports.tech_comparison_emit` caller and default-off (`emit_tech_comparison`,
`tech_comparison.scenarios`) — the synchronous HTTP report route and every committed scenario stay
byte-identical. Solar-only and hybrid-plus-BESS columns are deferred to a follow-up (those configs
do not yet exist).
