Blue Whale wind: battery options for the separate 9.5 MW wind project (no solar), screening only. New `conf/blue_whale_wind_bess_options.yaml`, `analytics/wind/wind_bess_options.py`, the Hydra CLI `scripts/run_blue_whale_wind_bess_options_v14.py` and `docs/blue_whale/wind_bess_options_summary.json` / `WIND_BESS_OPTIONS.md`. The base peak rate is the owner's "whole wind peak rate": PUCSL's solar + BESS formula with the wind tariff as R_charging, 20.80 / 0.90 + 27.08 + 4.93 / 0.90 = 55.67 LKR/kWh (BESS component 27.08 derived from both Table 7 lines). No option beats wind-only. The cheapest black-start battery is 0.5 MW / 0.5 MWh held, at about USD 79k of project NPV; every cycled option keeps a 0.5 MWh black-start reserve, and cycling 0.5 MW / 2 MWh with it costs about 125k. It does not firm a grid down-ramp: if a wind lull counts against the ramp limit, firming needs about the rated 9.5 MW at any allocation, which sets only the energy; at 0.79 MWh such a unit costs USD 0.55M-0.75M (generic battery supplier prices, owner-approved). The 40 MW black-start figure is UNCONFIRMED. No committed scenario or KPI changes.
