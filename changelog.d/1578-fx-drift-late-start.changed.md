- **A late FX drift replaces the USD opex path from its first drifted year, carrying on from the path's own level (#1578 L-12, owner rulings 2026-11-16).** When an FX drift stress departs from the authored curve only in a later year (an explicit `fx.curve` override that holds the authored rates for some years, or a per-year drift passed to the engine), the USD opex share keeps its own FX path until that first drifted year. From then on it follows the stressed curve's year-on-year moves from the level its own path had reached, so the path does not step onto the model curve. Before, the whole path was replaced, so the earlier years moved onto the model curve too. The year is read on each curve relative to its own spot, so a spot move alone is no drift. A drift from year 1 (any scalar drift override) and an override that names a drift key but leaves the curve where it was authored still run the USD share on the model curve itself, as ruled on 15 and 16 Nov. No committed scenario changes.
