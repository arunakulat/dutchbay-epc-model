- **A late FX drift replaces the USD opex path from its first drifted year (#1578 L-12, owner ruling 2026-11-16).** When an FX drift stress departs from the authored curve only in a later year (an explicit `fx.curve` override that holds the authored rates for some years, or a per-year drift passed to the engine), the stressed model curve now replaces the USD opex share's own FX path from that first drifted year onward, and the years before it keep the own path. Before, the whole path was replaced, so those earlier years moved onto the model curve too. The year is read on each curve relative to its own spot, so a spot move alone is no drift. A drift from year 1 (any scalar drift override) and an override that names a drift key but leaves the curve where it was authored still replace the whole path, as ruled on 15 and 16 Nov. No committed scenario changes.
