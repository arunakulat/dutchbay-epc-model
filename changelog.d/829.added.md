- **DEM ingest + terrain layers** (`analytics/gis/dem_ingest.py`, #829) — clip a local Copernicus GLO-30 (SRTM 1-arcsec fallback) DEM to a config bbox and derive elevation/slope/aspect/hillshade GeoTIFFs (Horn 3x3 kernel) with provenance sidecars + manifest entry, CASPER-guarded on the `[gis]` extra. Slope is physically correct by default: a geographic-CRS DEM (degree spacing — GLO-30's native grid) auto-converts pixel size to metres with latitude-aware per-axis factors, with an optional explicit `z_factor` override. Terrain input for the RIX diagnostic (#831) and slope-threshold siting mask (#833). KPI-neutral, add-only.
