- Run-mode toy-fallback ceiling is now wired into the debt engine (#733b). A declared lender/IC run (`run.mode` / `run_mode`, whose `analytics.run_modes` policy sets `allow_toy_capex=False`) hard-forbids the debt engine's toy CAPEX=100 and cost-free-debt fallbacks even where the config opted in — so a lender-grade run fails loud instead of silently presenting a fabricated capex or zero-interest debt. The permission is a CEILING, not a default: screening/developer (`allow_toy_capex=True`) and an undeclared mode leave the engine's opt-in semantics untouched. The pipeline resolves the mode and passes a plain `forbid_toy_fallback` bool to `plan_debt`, which stamps a reserved key onto its OWN config copy (never the caller's) so one chokepoint in `_allow_toy_capex_fallback` covers every capex-extraction and cost-free-debt site; finance does not import the analytics policy (no layer inversion). KPI-oracle byte-identical across all 27 committed scenarios; the committed lendercase (real capex + rates) is byte-identical with or without a declared lender mode.
