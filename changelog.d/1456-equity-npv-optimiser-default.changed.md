The capital-structure optimisers (`optimize_debt_mix`, `optimize_capex_contingency`, the Hydra CLI and its YAML) now default to `objective_key="equity_npv"` (maximised) instead of `equity_irr`. Under the refinance canon the equity IRR ranked debt mixes and contingency backwards, so a default run picked the dearest debt (#1456). An explicit `equity_irr` objective is still honoured, with a logged warning. The equity summary now carries `equity_cashflow_sign_changes` and `equity_irr_ranks_reliably`, and the waterfall logs a warning when equity cashflows change sign more than once; equity IRR itself is still reported. No pipeline KPI changes.
