- Lender report is stamped with its declared run-mode grade (#733c). When a scenario declares `run.mode` / `run_mode` (screening / developer / lender / ic), the report's cover metadata carries a "Run grade" line from that mode's `analytics.run_modes` policy `report_grade` — the same declaration the #733b debt-engine ceiling reads, so an artefact is labelled by the grade it was actually run at rather than the report's implicit lender framing. An undeclared mode leaves the report byte-identically ungraded (no grade line); a malformed declaration fails loud. Additive metadata only; KPI-neutral.
