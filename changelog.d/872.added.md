- **Grid-strength screen scaffold — SCR@POC + ANDES LVRT + advisory contract** (#872) —
  formalize the in-house grid-study PoC into `analytics.grid` (D1, on top of the D0
  fixture/extra). Adds `analytics/grid/short_circuit.py` — builds a
  `source → connection → POC` Thevenin network and computes the short-circuit ratio
  (`SCR = S_sc(POC) / S_plant`) via **pandapower IEC 60909** (both the MIN and MAX cases,
  the MIN case governing the screen), with a **closed-form Thevenin fallback** when
  pandapower is absent; and `analytics/grid/ride_through_poc.py` — one **ANDES** RMS
  low-voltage ride-through (LVRT) case parameterised from the D0 grid-code fixture. Both
  `pandapower` and `andes` are OPTIONAL `[grid]` deps guarded at call-time via
  `_require_pandapower()` / `_require_andes()` (CASPER) — never imported at module-import
  time, so the default (grid-free) install imports the package cleanly and the guards fail
  loud only when a grid entrypoint is called without the extra. Adds a frozen
  `GridStrengthResult` to `analytics.contracts_v14` (CCCDIR) that centralizes the
  IEC-60909-MIN-case rule, SCR banding (weak/marginal/strong → GFL-vs-GFM screen) and the
  bankability/EMT caveat: an in-house Python screen is always `bankable=False` (design-stage,
  not the utility-accepted PSS/E / PowerFactory study) and sets `emt_confirmation_required`
  when the SCR is weak enough that RMS screening cannot be trusted. Registers a strict,
  default-off top-level `grid` config block (`grid.study_enabled` gates the feature; no silent
  defaults — CESSPIT), validated only when a scenario declares the block. The screen is
  ADVISORY only — it never feeds the finance engine, so committed scenarios stay byte-identical
  (KPI-neutral). Default suite (grid-free) proves the CASPER guards; the pandapower/ANDES paths
  run in the opt-in `-m grid` lane with the `[grid]` extra installed.
