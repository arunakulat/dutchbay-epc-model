## Working here

- Route PGF work through this repository under `INTAKE-01`, then a branch and a pull request.
- Put source material, correspondence and anything derived from it verbatim in the private corpus.
- Bring only sanitised derivatives here: no source text, correspondence, commercial figures, named
  individuals or contact details. Describe the finding in general terms and cite the private file by
  its SHA-256.
- The private area is a dated snapshot. Read its `README.md` for its limits before relying on it.
