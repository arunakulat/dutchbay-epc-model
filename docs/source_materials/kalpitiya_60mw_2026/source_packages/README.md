## Why this package is manifest-only

Stated once, in the header of the manifest above, under `KALPITIYA60MW-WIND-HANDLING-2026-09-21`.
It covers the two grounds of restriction, the absence of any authorization instrument, why
`PUBLICATION_AUTHORIZATION.md` does not reach this material, and what the recorded filenames
themselves still disclose. This page does not summarise it, because a summary is a second copy and
a second copy drifts.

The same route was selected twice before in this project, for the NSO 250 MW checklist dossier and
for the 3 September commercial offers. The reasoning in the offers case is recorded at
`NSO250MW-OFFERS-HANDLING-2026-09-04`, in
`../../nso_bess_250mw_2026/source_packages/NSO250MW_Commercial_Offers_2026-09-03.MANIFEST.sha256`.

**Private hosting is a different question from publication.** Holding the same material in a
private repository is storage, not distribution, and is ordinary use of material received for the
purpose. The residual control there is access breadth: every collaborator on the private
repository receives the whole package. Keep that list minimal.
