handovers, iteration audits, and implementation-status snapshots. They are kept
for provenance but are **superseded** and should not be treated as the current
state of the codebase.

For the authoritative current architecture see
[`docs/ARCHITECTURE.md`](../ARCHITECTURE.md). For ongoing model state and history
see `CHANGELOG.md` at the repo root.
