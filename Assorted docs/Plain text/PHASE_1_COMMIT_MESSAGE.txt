feat(analytics): Phase 1 - Evaluation gateway + sensitivity/MC bridges

### Overview
Phase 1 establishes the canonical analytics architecture:
- evaluation_v14: Single evaluation gateway (evaluate_scenario + lazy loading)
- sensitivity_v14: Refactored to use SensitivityResult contract
- monte_carlo_bridge_v14: MC-specific KPI snapshot bridge

### Changes Made

#### 1. analytics/evaluation_v14.py (NEW)
- ✓ evaluate_scenario(config_path, overrides) → dict[str, float]
  - CANONICAL entry point for all analytics evaluations
  - Accepts nested override dict for parameter injection
  - Returns flat normalized KPI dict
- ✓ evaluate_scenario_from_dict(config, overrides)
  - Optimization: skip YAML parsing when config pre-loaded
  - Used by sensitivity/MC to eliminate redundant I/O
- ✓ _deep_merge_config(base, overrides) → dict
  - Recursively merges nested override dicts
- ✓ normalize_kpi_dict(raw_kpis) → dict[str, float]
  - Enforces canonical KPI names (single source of truth)
  - Contract enforcement: KeyError if required KPIs missing
- ✓ Instrumentation: timing + debug logging
  - Helps identify bottlenecks during Phase 2 optimization

#### 2. analytics/sensitivity_v14.py (REFACTORED)
- ✓ Added SensitivityResult dataclass
  - base_kpis: Dict[str, float]
  - shocked_kpis: Dict[str, Dict[str, Dict[str, float]]]
  - Internal Phase 1 contract (will be public in Phase 2)
- ✓ Added _build_nested_override(param_path, value) → Dict[str, Any]
  - THE ONLY place that maps param → overrides
  - Converts "foo.bar.baz" → {"foo": {"bar": {"baz": value}}}
- ✓ Added _evaluate_base_kpis(config_path) → Dict[str, float]
  - Gateway for unshocked evaluation via evaluate_scenario()
- ✓ Refactored _analyze_single_parameter()
  - All evaluations go through evaluate_scenario() only
  - Down/up shocks properly isolated
- ✓ Refactored run() to return SensitivityResult
  - Internal API change (backwards compatibility wrapper in progress)
- ✓ No direct imports from finance.cashflow_v14, finance.debt_v14, finance.metrics
  - Imports only from analytics.evaluation_v14

#### 3. analytics/monte_carlo_bridge_v14.py (NEW)
- ✓ MonteCarloKpiSnapshot dataclass (frozen)
  - Immutable snapshot of MC-relevant KPIs
  - project_irr, equity_irr, min_dscr, avg_dscr
- ✓ evaluate_for_monte_carlo(config_path, overrides) → MonteCarloKpiSnapshot
  - Entry point for MC engine
  - Uses evaluate_scenario() gateway (same as sensitivity)
- ✓ evaluate_for_monte_carlo_as_dict() variant
  - Legacy compatibility for existing MC engines
- ✓ Clear error handling (KeyError, TypeError with context)

#### 4. tests/analytics_layer/test_sensitivity_v14.py (NEW)

- ✓ test_sensitivity_directional()

- ✓ test_build_nested_override()

#### 5. tests/analytics_layer/test_monte_carlo_bridge_v14.py (NEW)

  - Legacy compatibility variant
