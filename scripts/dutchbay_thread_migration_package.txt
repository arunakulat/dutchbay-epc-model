Core Components
1. "Go With The Flow" Ruleset
YAML/config-driven first: All scenario, parameter, and pipeline configs use YAML with environment-sensitive overlays.
Defensive programming: Always validate configs and parameter ranges before compute.
Batch/CLI friendly: No function has hardcoded paths or states. Inputs/outputs routed by argument or env variable.
Test-first design: All analytics (sensitivity, Monte Carlo, batch, export) are tested by docstring/example/test scaffolds.
Stateless APIs and results: Any analytic/result must be callable/reproducible by REST UI and script.


2. Technical Notebook — Proven Patterns
YAML loading: Always use safe_load; wrap in try/except for IO/Type errors.
Validation: Use explicit dataclasses or Pydantic for parameter and scenario config validation.
Batch: Provide CLI wrappers for all analytics, supporting headless/batch use (.py, not notebooks only).
Generation: Reports, charts, exports always save to explicit target folders (never overwrite defaults).
Testing: Minimal test for every analytic contract in tests/contracts/, with edge/fuzz tests for safety.


3. Active To-Do List
Phase 1: Publish/validate scenario loader and YAML driver configs. Expose core analytics (summary, cashflow, kpis).
Phase 2: Make tornado/sensitivity, Monte Carlo, validation (guard) available as Streamlit and REST.
Phase 3: End-to-end reporting (Excel, Markdown, PNG). Health/audit tracking UI.
Phase 4-5: Scenario compare/audit, optimizer, history, user notes, DFI/board presentation mode.
Tech debt: Remove/merge any legacy handler code, document all module entrypoints, complete OpenAPI doc for REST facade.


4. Diagnostic Checklists
Validate YAML: yamllint or python -c 'import yaml; yaml.safe_load(open("file.yaml"))'
Validate parameter sweep: Run validate_parameter_ranges(config, params) and check error DataFrame.
Integration smoke test: CLI + pytest green for analytics, contracts, and export/test folders.
Batch processing: Ensure all outputs (CSV, Excel, PNG, logs) go to /exports/ with unique run names.


5. Command Reference
Run scenario: python analytics/run_full_pipeline.py --config scenarios/scenario.yaml
Run Streamlit: streamlit run dashboard/streamlit_app.py
Serve REST API: uvicorn api.sensitivity_api:app --reload
Run all tests: pytest tests/
Git: git checkout -b feature/xyz, git commit -am "...", git push
Deploy to server: git pull && pip install -r requirements.txt && supervisorctl restart epc-app
